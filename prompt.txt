Go

// Service 定义了从后端获取的单个服务的数据结构
type Service struct {
    ServiceID   int    `json:"service_id"`
    ServiceName string `json:"service_name"`
    Activated   bool   `json:"activated"`
}

// ServiceHallView 是我们的主UI组件
type ServiceHallView struct {
    fyne.CanvasObject

    // 依赖项
    window          fyne.Window
    netManager      *network.Manager // 引用网络管理器
    userID          int

    // 内部状态和组件
    services        []Service // 存储从服务器获取的服务列表
    serviceList     *widget.List // Fyne的列表组件
    onEnterService  func(serviceID int, serviceName string) // 切换到服务界面的回调函数
}
步骤 2.2：实现UI组件的构造函数和静态布局
创建ServiceHallView的构造函数NewServiceHallView。

函数签名应为 func NewServiceHallView(window fyne.Window, netManager *network.Manager, userID int, onEnter func(int, string)) *ServiceHallView。

在函数内部，初始化ServiceHallView结构体。

创建view.serviceList。这是一个widget.NewList，为其提供三个回调函数的框架（Length, CreateItem, UpdateItem）。

使用一个垂直布局容器 (container.NewVBox) 将一个标题标签（例如widget.NewLabel("服务大厅")）和view.serviceList组合起来，并将其赋值给view.CanvasObject。

步骤 2.3：实现列表项的动态更新逻辑
详细实现widget.NewList中的UpdateItem回调函数的逻辑。

在UpdateItem回调函数中，获取对应索引的服务数据serviceData。

获取列表项模板中的Label和Button组件。

设置Label的文本为serviceData.ServiceName。

根据serviceData.Activated的值，设置按钮的文本和行为：

如果Activated为true，按钮文本设为“进入管理”，其OnTapped事件应调用view.onEnterService(serviceData.ServiceID, serviceData.ServiceName)。

如果Activated为false，按钮文本设为“开通服务”，其OnTapped事件应调用view.netManager.ActivateService(...)，并在成功后调用view.refreshServices()方法来刷新整个列表。

步骤 2.4：实现数据获取和刷新逻辑
为ServiceHallView添加一个名为refreshServices的新方法。

在该方法中，调用view.netManager.QueryUserServices(view.userID)。

如果成功，解析返回的JSON数据，并将其填充到view.services切片中。

最后，必须调用view.serviceList.Refresh()来更新UI的显示。

步骤 2.5：完成初始加载
在NewServiceHallView构造函数的末尾，返回view之前，启动一个新的goroutine来调用view.refreshServices()，以防止UI在等待网络响应时被阻塞。
